## 💜 Sobre o projeto

O **PONTO GAMER** é um catálogo virtual de produtos gamers desenvolvido como projeto prático da disciplina de Programação Web do curso Técnico em Desenvolvimento de Sistemas da ETEC.

Com uma identidade visual autoral, o projeto combina tecnologia, criatividade e design, trazendo uma estética gamer feminina com tons de rosa, lilás e roxo.

A proposta é apresentar uma experiência visual agradável para quem deseja montar ou personalizar seu setup gamer.

## 🌐 Demonstração online

O projeto está disponível publicamente através da Vercel, permitindo que você explore o catálogo diretamente pelo navegador, sem precisar instalar ou baixar arquivos.

## ✨ Funcionalidades

- 🛒 Catálogo virtual de produtos gamers.
- 🖥️ Componentes de hardware e periféricos.
- 🎮 Consoles, acessórios e cadeiras gamers.
- 🏷️ Cards personalizados com imagens, descrições e preços.
- 💻 Apresentação visual de um setup gamer.
- 🎬 Vídeo integrado ao monitor do setup.
- 🔐 Formulários de login e cadastro.
- 📱 Layout responsivo.
- 🎨 Logotipo e identidade visual próprios.

## 🚀 Como executar o projeto

### Acessar online

Acesse diretamente pelo navegador:

**[ponto-gamer.vercel.app](https://ponto-gamer.vercel.app/)**

### Executar localmente

1. Clone este repositório:

```bash
git clone https://github.com/truemelloo/PONTO-GAMER.git
```

2. Acesse a pasta do projeto:

```bash
cd PONTO-GAMER/Ponto_Gamer/Ponto_Gamer/Ponto_Gamer
```

3. Execute o arquivo `index.html` no navegador.

Não é necessário instalar dependências.

## 📚 Objetivo acadêmico

Aplicar os conhecimentos adquiridos nas aulas de Programação Web, explorando:

- Estruturação de páginas HTML.
- Estilização com CSS.
- Organização de produtos em cards.
- Navegação entre páginas.
- Construção de formulários.
- Responsividade e design de interfaces.

> Este projeto possui finalidade exclusivamente educacional e demonstrativa, sem processamento real de compras ou autenticação de usuários.
